# Executor profile: generic

Use for any model without a specific profile.

- The card defines the outcome. Reach it by the simplest route the codebase allows.
- Before writing code, ask whether it needs to exist, then whether the repository, standard library, platform, or an existing dependency already does it.
- Keep the diff small and on task. Leave style and unrelated refactors alone.
- After fixing something, search for the same pattern elsewhere in the files you touched.
- Run the acceptance commands yourself and paste real output in the report.
- Reversible doubts: decide, note it, continue. Stop only for what the card lists.
- Write the result file once at the end. Write no placeholder before that.
